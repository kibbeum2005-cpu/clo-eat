# 옷장 파먹기 👕

> 새 옷 사기 전에, 이미 가진 옷부터 제대로 입어 보자.
> 옷 한 벌의 **1회당 비용**을 계산하고, **오늘의 TPO에 맞는 착장**을 점수로 확인하고, **착장 기록**을 달력에 쌓아 가는 대학생용 패션 관리 웹 앱입니다.

**🔗 배포 주소: https://clo-eat.vercel.app**
소스 코드: https://github.com/kibbeum2005-cpu/clo-eat

---

## 서비스 소개

옷을 사 놓고 몇 번 입지도 않고 또 새 옷을 사게 되는 일, 많죠. **옷장 파먹기**는 내가 가진 옷을 등록해 두고 입을 때마다 기록하면서, 그 옷이 **얼마나 본전을 뽑았는지** 눈에 보이게 만들어 줍니다.

- 구매가를 입은 횟수로 나눈 **1회당 비용**이 2,000원 이하가 되면 **"뽕뽑기 성공 🏆"** 배지가 붙습니다.
- 오늘 입을 옷을 고르면 상황(TPO)에 어울리는지 **0~100점**으로 알려 주고, 최근 3일 안에 입은 옷이면 **"짱구 옷장 경고!"** 를 띄웁니다.
- 입은 날을 **달력에 사진·별점·메모와 함께** 남기고, **영수증**으로 그날 착장의 가치를 확인합니다.

외부 AI API는 쓰지 않고, 모든 점수와 총평은 직접 만든 규칙(순수 JS)으로 계산합니다.

## 주요 기능

### 🔐 로그인
- 이메일 + 비밀번호 회원가입 / 로그인, **닉네임** 설정(화면에는 이메일 대신 닉네임이 보임)
- 비밀번호 찾기(재설정 메일) 지원
- 옷장은 **계정별로 완전히 분리**됩니다. 다른 사람의 데이터는 볼 수도, 바꿀 수도 없습니다.

### 👕 내 옷장
- **옷 등록 · 수정 · 삭제**: 사진, 이름, 브랜드, 구매 가격, 카테고리, 스타일 태그
- **내 별점**: 얼마나 마음에 드는지 5점 만점, 0.5점 단위(10단계)
- **입은 횟수**: 새 옷은 0회에서 시작하고, 앱을 쓰기 전에 입은 횟수가 있으면 "기존 입은 횟수"로 넣을 수 있음(나중에 다시 수정 가능). 착장을 기록하면 거기에 +1씩 쌓임
- **1회당 비용** 자동 계산, 2,000원 이하이면 "뽕뽑기 성공 🏆"
- **필터**: 카테고리 / 태그 / 브랜드 / 별점(전체·별점 없음·5점만·4.5점 이상·4점 이상·3점 이상·2점 이하)을 조합해서 모아보기
- **정렬**: 최근 등록순 · 이름순 · 최근 입은 순 · 많이 입은 순 · 별점 높은 순, **한 페이지 10벌**씩 넘겨 보기
- **선택 수정**: 여러 벌을 골라 한 번에 **삭제**하거나 **카테고리 · 브랜드 · 태그를 일괄 변경**(태그는 추가/제거/교체 중 선택)
- **카테고리 · 태그 관리**: 직접 추가하고, 기본 항목까지 포함해 이름 수정 · 삭제 가능(옷과 TPO에 들어 있는 같은 이름도 함께 바뀜)

### ✨ 오늘 입기
- **TPO 선택**: 9시 전공수업 · 도서관 밤샘 · 소개팅 · 과 동아리 모임 · 홍대 클럽이 기본이고, **직접 추가 · 수정 · 삭제**할 수 있음(이름, 이모지, 어울리는/피할 스타일, 한마디)
- 카테고리별로 옷을 골라 코디 구성
- **TPO 핏체크**: 기본 50점에서 시작해 어울리는 스타일의 옷은 +12점, 피해야 할 스타일은 -15점. 점수와 한마디, 항목별 가감 내역을 보여 줌
- **짱구 옷장 경고 🚨**: 최근 3일 안에 입은 옷이 있으면 경고 모달
- **오늘의 착장 확정**: 선택한 옷의 입은 횟수를 +1 하고 기록 저장. **별점과 착장 사진**도 선택으로 남길 수 있음

### 🗓️ 달력
- 월별 달력에 날마다 **대표 사진**(그날 올린 착장 사진 → 없으면 옷 사진)을 표시
- **과거 · 미래 날짜에도 착장 기록 가능** (미래는 "예정 착장"으로 저장되고, 그날이 지나면 입은 횟수에 반영)
- 기록한 착장의 **TPO · 입은 옷 수정**(바뀐 옷만 입은 횟수 자동 조정), **메모 · 별점 · 사진 수정**, 기록 삭제
- **월 총평 한 줄**: 그 달의 기록 일수, 가장 아껴 입은 옷, 자주 나간 자리, 본전 뽑은 옷 수
- **별점 모아보기**: 별점을 남긴 착장을 기준(5점만 / 4점 이상 / 2점 이하 등)별로 모아서 보고, 누르면 그날로 이동
- 기록한 날의 **영수증** 바로 보기

### 🧾 영수증
- 오늘 착장을 **마트 영수증** 모양으로 표시: 옷별 가격 · 입은 횟수 · 1회당 비용, 착장 **총 가치**, **평균 1회당 비용**
- 평균 1회당 비용에 따라 칭호 부여: 👑 뽕뽑기 마스터 · 💰 알뜰 대학생 · 🌱 성장하는 알뜰러 · 🛍️ 새 옷 모시는 중

| 영역 | 사용 기술 |
|---|---|
| 프런트엔드 | Vite 5 · 순수 JavaScript(ES Modules) · Tailwind CSS v4 · Lucide Icons |

## 직접 실행해 보기

```bash
git clone https://github.com/kibbeum2005-cpu/clo-eat.git
cd clo-eat
npm install
cp .env.example .env     # 아래 두 값을 채우세요
npm run dev              # http://localhost:5173
```

`.env`

```
VITE_SUPABASE_URL=https://<프로젝트-id>.supabase.co
VITE_SUPABASE_ANON_KEY=<Supabase의 publishable(anon) key>
```

> `service_role` 같은 **비밀 키는 절대 넣지 마세요.** 브라우저에 노출되는 값은 공개용 키뿐입니다.

### 내 Supabase 프로젝트로 구성하기
1. Supabase에서 새 프로젝트를 만들고 **SQL Editor**에서 `supabase/schema.sql` 전체를 실행합니다(여러 번 실행해도 안전하게 작성돼 있음).
2. **Authentication → URL Configuration**에서 Site URL과 Redirect URLs에 서비스 주소(`http://localhost:5173`, 배포 주소)를 추가합니다.
3. 바로 가입되게 하려면 **Authentication → Sign In / Providers → Email**에서 이메일 인증 확인을 끕니다.

### 배포 (Vercel)
1. 이 저장소를 Vercel 프로젝트로 연결합니다(Framework: Vite 자동 감지).
2. Vercel **Environment Variables**에 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`를 등록합니다.
3. `main`에 푸시하면 자동으로 배포됩니다.

### DB 자동 반영 (선택)
`supabase/schema.sql`을 바꿔서 `main`에 푸시하면 `.github/workflows/db-migrate.yml`이 Supabase DB에 자동으로 실행합니다.
GitHub 저장소 **Settings → Secrets and variables → Actions**에 `SUPABASE_ACCESS_TOKEN`을 등록해야 동작하며, 없으면 건너뜁니다. 테이블·컬럼 삭제 같은 되돌릴 수 없는 SQL이 새로 추가되면 자동 실행을 멈추고 수동 실행을 요구합니다.

## 보안

- 모든 테이블에 **Row Level Security**를 적용해 사용자는 본인 데이터만 읽고 쓸 수 있습니다. 비로그인 상태의 조회·쓰기·함수 호출은 모두 거부됩니다.
- 옷 · 착장 사진은 **비공개 저장소**에 사용자별 폴더로 저장되고, 임시 주소로만 보여 줍니다.
- 사용자가 입력한 모든 값은 화면에 넣기 전에 이스케이프합니다(XSS 방지).
- 배포 사이트에는 **CSP**, 클릭재킹 방지, MIME 스니핑 방지 등의 보안 헤더가 설정돼 있습니다(`vercel.json`).

## 폴더 구조

```
src/
  main.js            진입점 · 로그인 상태에 따라 화면 전환
  app.js             헤더(닉네임) · 탭
  auth.js            로그인 / 회원가입 / 비밀번호 찾기 화면
  closet.js          내 옷장 (등록·수정·삭제·필터·정렬·선택 수정)
  today.js           오늘 입기 (TPO 핏체크 · 짱구 옷장 경고 · 착장 확정)
  tpoManager.js      TPO 추가·수정·삭제
  ootd.js            달력 (기록·수정·메모·별점·사진·총평·별점 모아보기)
  receipt.js         영수증
  lib/               순수 로직과 Supabase API (비용 계산, 핏체크, 필터·정렬, 별점 등)
supabase/schema.sql  테이블 · 보안 정책 · DB 함수 전체
.github/workflows/   DB 자동 반영
vercel.json          보안 헤더
```
